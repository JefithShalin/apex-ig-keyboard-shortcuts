## Oracle APEX Interactive Grid Keyboard Shortcuts

### Overview

This project enhances the usability of Oracle APEX Interactive Grids by introducing keyboard shortcuts for common actions. It helps users perform operations quickly without relying on mouse interactions.

### Features

* Add new rows using a keyboard shortcut
* Delete selected rows easily
* Save changes quickly
* Refresh the grid instantly
* Improved navigation experience similar to spreadsheet tools

### Prerequisites

* Oracle APEX application with an Interactive Grid
* Interactive Grid must be enabled for editing

### Setup

* Ensure the Interactive Grid is editable
* Assign a Static ID to the grid
* Configure the page to focus on the grid when it loads
* Add the required initialization logic in the grid settings

### Usage

Once configured, users can perform common grid operations using predefined keyboard shortcuts, improving speed and efficiency during data entry.

### Benefits

* Reduces dependency on mouse actions
* Speeds up data entry and updates
* Improves overall user experience
* Easy to integrate into existing applications

### Compatibility

Works with standard Oracle APEX Interactive Grid components that support editing and actions.
